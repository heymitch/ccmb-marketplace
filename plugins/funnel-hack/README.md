# Funnel Hack

Reverse-engineer a competitor's funnel and adapt it to *your* brand — not generic "post more, build a list" advice.

## Install

After adding the marketplace (`heymitch/ccmb-marketplace`), install from the plugin list or:

```
/plugin install funnel-hack@ccmb-marketplace
```

## Use

Say "funnel-hack [competitor]" or "do a competitor teardown of [X]". The skill reads your working-dir brand config first (mission, voice, ICP, offer ladder), then snaps every steal / differentiate / content-idea to your actual positioning.

## What's inside

- `skills/funnel-hack/SKILL.md` — the teardown workflow (CONFIG → scan → ADAPT-TO-\<brand\>.md)
- `skills/funnel-hack/PLAYBOOK.md` — the teardown playbook
- `skills/funnel-hack/REPORT-TEMPLATE.md` — output template

## Pairs with Skyscraper

Funnel-hack reverse-engineers a *specific competitor's* funnel. [Skyscraper](../skyscraper/) scans the *whole landscape* of existing solutions before you build. Different jobs — install both if you want the full competitive-intel pair.

## The key move

Step 0 reads your brand config so the output is draft-ready in *your* voice. Skip it and you get bland generic advice — the config step is what makes the teardown useful.
