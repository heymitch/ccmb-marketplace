# Common risks (fallback catalog for Layer 5)

When a student blanks on Q15/Q16 (audience objections + execution risks), the agent draws from this catalog and asks to confirm/edit. NEVER use these silently — always surface as suggestions.

## Common audience objections by persona type

### B2B SaaS founders / operators
- "Already using [competitor]. Switching cost is real."
- "Pricing isn't transparent / feels expensive."
- "Don't trust new SaaS — what if you shut down?"
- "Don't have time to learn another tool."
- "My team won't adopt it."

### Creators / solopreneurs
- "I can build this myself for free."
- "Subscription fatigue."
- "Sounds too good to be true."
- "I'm not technical enough to use this."
- "I tried [similar thing] and it didn't work for me."

### Marketers / agency owners
- "Already have a stack. Don't want to consolidate."
- "Clients won't pay for this."
- "Doesn't integrate with [our existing tool]."
- "Looks like another point solution."

### Coaches / consultants / service businesses
- "I sell time, not tools — this isn't for me."
- "Too much setup before I see value."
- "My audience isn't online enough for this."
- "AI feels impersonal for what I do."

### Enterprise buyers
- "Security review will take 6 months."
- "Procurement won't approve under $10k."
- "Need SOC2 / HIPAA / GDPR compliance docs."
- "Already using [enterprise vendor]."

## Common execution risks for solo operators

- "No existing email list >500."
- "LinkedIn algo deprioritizes new accounts."
- "Vercel Cron not set up yet."
- "I might get sick / travel during the launch window."
- "I'm relying on a referral that may not land."
- "Voice / brand assets not finalized."
- "Don't have proof points / testimonials yet."
- "Single point of failure: only one channel."
- "Burnout risk — cadence may not be sustainable."
- "Underestimating asset production time."

## Common execution risks for teams

- "Stakeholder approval cycles will slow ship."
- "Marketing + sales not aligned on positioning."
- "Engineering needs to ship a feature for the launch — risk of slip."
- "Brand guidelines haven't been finalized."
- "Legal/compliance review pending."
- "Paid ads team needs 2 weeks lead time."

## How the agent uses this

When student blanks on Q15:

> *"Common objections for [audience type] include: [pull 3 from the right section]. Which of these apply, and what would you add?"*

When student blanks on Q16:

> *"Common execution risks for solo operators: [pull 3 from solo section]. Which apply? Anything else specific to your situation?"*

Never write these to the brief without explicit student confirmation. The catalog is conversation starter, not autofill.
